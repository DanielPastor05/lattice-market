# Development workflow

Before drafting a large plan, when an error repeats, and before declaring a long
task complete, spawn the architect to review the relevant evidence and address
its findings. Architect reviews must not recursively spawn another architect.

After every implementation phase, run the relevant checks, resolve review
findings, commit that phase and push to the configured GitHub remote. Keep phases
in separate commits. Report a failed push or missing authentication explicitly;
do not describe local commits as published.
